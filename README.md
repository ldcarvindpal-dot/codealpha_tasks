# CodeAlpha Python Programming Internship - Tasks

This repository contains the tasks completed as part of the **Python Programming Internship** at **CodeAlpha**.

## Tasks Completed

### Task 1: Hangman Game
A simple text-based Hangman game where the player guesses a word one letter at a time.
- File: `hangman_game.py`
- Concepts used: random, while loop, if-else, strings, lists

### Task 2: Stock Portfolio Tracker
A simple stock tracker that calculates total investment based on manually defined stock prices.
- File: `stock_portfolio_tracker.py`
- Concepts used: dictionary, input/output, basic arithmetic, file handling

### Task 4: Basic Chatbot
A simple rule-based chatbot that responds to predefined user inputs.
- File: `basic_chatbot.py`
- Concepts used: if-elif, functions, loops, input/output

## How to Run

Each file can be run directly using Python:

```
python hangman_game.py
python stock_portfolio_tracker.py
python basic_chatbot.py
```
